# AGENTS.md

Instruções para agentes de IA (Cursor, Codex, Copilot e outros) neste repositório.

As regras, convenções e o fluxo de trabalho do projeto estão em **[HARNESS.md](HARNESS.md)** — leia esse arquivo inteiro
antes de qualquer alteração. O que construir está em [docs/SPEC.md](docs/SPEC.md).

Resumo do que nunca fazer: executar SQL ou alterar o banco; versionar segredos (`.env`); avançar de etapa sem a validação do dono;
terminar um prompt que alterou o projeto sem relatório em `docs/relatorios/`; criar repositório git ou commitar sem pedido do dono.
